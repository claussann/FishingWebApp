DALLA PREPARAZIONE AL RICORDO

Un posto per tutta la tua passione.

Fishing Inventory è un quaderno digitale per organizzare ciò che usi e ricordare ciò che impari. Nel catalogo puoi annotare nome, grammatura, quantità e tecnica di ogni canna, mulinello o accessorio: prima di una sessione basta una ricerca per ritrovare il materiale giusto.

Gli spot collegano un luogo alle tue osservazioni. Salva coordinate, tipo di ambiente e una foto; nel diario abbina lo spot all’attrezzatura utilizzata. Tornando sulla stessa zona potrai rileggere le note sulle condizioni e confrontare le uscite, senza affidarti alla memoria.

💾 Come funziona il Salvataggio

📱
Android (Chrome)

Il file viene scaricato automaticamente. Trovi fishing-inventory-backup-DATA.json nella cartella Download del tuo telefono, oppure nelle notifiche in basso.

🍎
iPhone / iPad (Safari)

Tocca Condividi → Salva su File per salvare nell'app File. Puoi poi trovarlo in Il mio iPhone → Download.

💻
PC / Mac

Il file va nella cartella Download configurata nel browser. Su Chrome puoi scegliere dove salvarlo dalle impostazioni.

💡
Sostituzione file

Per sostituire il vecchio backup attiva il Salvataggio Automatico nella Home: ogni modifica salva automaticamente sul file scelto (solo browser compatibili con File System Access API).

📂 Come funziona il Caricamento

📁
Seleziona il file di backup

Scegli il file .json precedentemente salvato con il tasto 💾 Salva. Funziona sia da PC che da smartphone.

📱
Da smartphone

Cerca il file nella cartella Download o dove lo hai salvato. Su iPhone controlla l'app File.

⚠️
Importazione protetta

Puoi unire il file ai tuoi dati oppure sostituirli. Prima della conferma l’app conserva una copia di recupero locale. Un backup esterno resta consigliato.

🔄
Cambio dispositivo

Salva il file sul vecchio dispositivo, trasferiscilo (email, cloud, WhatsApp a te stesso) e caricalo sul nuovo. Tutti i dati e le foto vengono ripristinati.
